# Émeraude AI

## Локальный запуск с Gemini

1. Установите Node.js 20 или новее.
2. В терминале перейдите в папку `emeraude-ai`.
3. Создайте локальный файл настроек:

   ```powershell
   Copy-Item .env.example .env
   ```

4. Откройте `.env` и замените `вставьте_ключ_сюда` на свой Gemini API key.
5. Запустите сайт:

   ```powershell
   npm start
   ```

6. Откройте `http://127.0.0.1:3000`.

Ключ хранится только в `.env` и не отправляется в браузер. Не публикуйте `.env` и не добавляйте ключ в исходный код. Сервер запускается только на этом компьютере. Бесплатный лимит запросов зависит от аккаунта Gemini; при его исчерпании сайт покажет сообщение и предложит попробовать позже.
