# Émeraude AI

## Локальный запуск с Gemini

1. Установите Node.js 20 или новее.
2. В терминале перейдите в папку `emeraude-ai`.
3. Создайте локальный файл настроек:

   ```powershell
   Copy-Item .env.example .env
   ```

4. Откройте `.env` и замените `вставьте_ключ_сюда` на свой Gemini API key.
5. Запустите сайт:

   ```powershell
   npm start
   ```

6. Откройте `http://127.0.0.1:3000`.

Ключ хранится только в `.env` и не отправляется в браузер. Не публикуйте `.env` и не добавляйте ключ в исходный код. Сервер запускается только на этом компьютере. Бесплатный лимит запросов зависит от аккаунта Gemini; при его исчерпании сайт покажет сообщение и предложит попробовать позже.

## Публичный запуск для преподавателя

В репозитории есть файл `render.yaml` для бесплатного деплоя на Render:

1. Откройте [render.com](https://render.com) и войдите через GitHub.
2. Выберите **New → Blueprint** и укажите репозиторий `ramazan1506/Emeraud`.
3. Render прочитает `render.yaml`, установит Node.js-проект и создаст веб-сервис.
4. В настройках сервиса добавьте значение `GEMINI_API_KEY` со своим новым Gemini API key.
5. Нажмите **Deploy** и откройте выданный Render URL.

Эту ссылку можно отправить преподавателю: он увидит работающий сайт и сможет пользоваться ИИ-консультантом. Ключ хранится в настройках Render и в GitHub не публикуется. Не используйте ключ, который уже отправляли в переписке; создайте новый в Google AI Studio.

## Запуск на Vercel

1. Откройте [vercel.com/new](https://vercel.com/new) и войдите через GitHub.
2. Найдите репозиторий `ramazan1506/Emeraud` и нажмите **Import**.
3. В поле **Root Directory** выберите `emeraude-ai`.
4. Откройте **Environment Variables** и добавьте `GEMINI_API_KEY` со своим новым ключом.
5. Добавьте `GEMINI_MODEL` со значением `gemini-3.5-flash-lite`.
6. Нажмите **Deploy**. После завершения Vercel выдаст публичную ссылку на сайт.

Файл `api/chat.mjs` нужен Vercel для безопасного обращения к Gemini. Ключ не хранится в браузере и не попадает в GitHub.
